# Manuelle Baseline: Simple To-do List

Die Anwendungsidee ist eine einfache App zum Erstellen, Bearbeiten und Abhaken von Aufgaben.

## Requirements

- Benutzer können neue Aufgaben erstellen.
- Benutzer können bestehende Aufgaben bearbeiten.
- Benutzer können Aufgaben löschen.
- Benutzer können Aufgaben als erledigt markieren.
- Benutzer können offene und erledigte Aufgaben anzeigen.

## User Stories

- Als Benutzer möchte ich eine Aufgabe erstellen, damit ich wichtige Tätigkeiten festhalten kann.
- Als Benutzer möchte ich eine Aufgabe bearbeiten, damit ich Änderungen nachträglich eintragen kann.
- Als Benutzer möchte ich eine Aufgabe als erledigt markieren, damit ich meinen Fortschritt sehen kann.
- Als Benutzer möchte ich Aufgaben löschen, damit die Liste übersichtlich bleibt.
