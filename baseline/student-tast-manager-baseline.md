# Manuelle Baseline: Student Task Manager

Die Anwendungsidee ist eine App, mit der Studierende Aufgaben für verschiedene Kurse verwalten können.

## Requirements

- Benutzer können Aufgaben erstellen.
- Benutzer können Aufgaben einem Kurs zuordnen.
- Benutzer können ein Fälligkeitsdatum festlegen.
- Benutzer können Aufgaben bearbeiten.
- Benutzer können Aufgaben löschen.
- Benutzer können Aufgaben als erledigt markieren.
- Benutzer können offene und erledigte Aufgaben anzeigen.

## User Stories

- Als Student möchte ich eine Aufgabe erstellen, damit ich meine Abgaben festhalten kann.
- Als Student möchte ich eine Aufgabe einem Kurs zuordnen, damit ich meine Aufgaben besser organisieren kann.
- Als Student möchte ich ein Fälligkeitsdatum eintragen, damit ich Deadlines nicht vergesse.
- Als Student möchte ich Aufgaben als erledigt markieren, damit ich meinen Fortschritt sehen kann.
- Als Student möchte ich Aufgaben löschen, damit meine Liste übersichtlich bleibt.
