# Simple Prompt

Dieser Prompt wird verwendet, um ohne zusätzliche Strukturierung erste KI-generierte Requirements und User Stories zu erhalten.

## Prompt

Erstelle Requirements und User Stories für eine einfache To-do-Listen-App.

## Ziel

Der Prompt soll zeigen, welche Ergebnisse entstehen, wenn nur eine kurze und allgemeine Beschreibung der Anwendung gegeben wird.
