# Slides Notes

Diese Datei sammelt erste Notizen für die spätere Präsentation.

## Kernaussage

KI kann bei der Erstellung von Requirements und User Stories unterstützen, ersetzt aber keine fachliche Prüfung.

## Präsentationsidee

Das Projekt wird anhand von zwei einfachen Anwendungsideen gezeigt:

- Simple To-do List
- Student Task Manager

Für beide Ideen werden manuelle Baselines erstellt und mit KI-generierten Ergebnissen verglichen.

## Wichtige Punkte für die Präsentation

- Unterschied zwischen einfachem, strukturiertem und iterativem Prompt zeigen
- Ergebnisse von ChatGPT und Gemini vergleichen
- Beispiele für gute Ergänzungen zeigen
- Beispiele für fehlende oder unpassende Punkte zeigen
- Am Ende bewerten, welche Methode am besten funktioniert hat
